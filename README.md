# Emergency Ambulance Dispatch System Backend

Node.js + TypeScript + Express.js scaffolding project.

## Requirements

- Node.js (v18 or higher)
- npm or yarn

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run in development mode:
   ```bash
   npm run dev
   ```

3. Build the project:
   ```bash
   npm run build
   ```

4. Run the production build:
   ```bash
   npm start
   ```

5. Lint and format code:
   ```bash
   npm run lint
   npm run format
   ```

## API Routes

- `GET /api/v1/health` - Health check route
